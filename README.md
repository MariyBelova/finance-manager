# Личный финансовый трекер (учебный проект)

Консольное приложение для учёта доходов и расходов, бюджетов и отчётов. Проект выполнен в рамках дисциплины «Системное администрирование» (capstone).

## Технологии
- Java 17+
- Maven
- JUnit Jupiter (тесты)
- GitHub Actions (CI)

## Возможности
- Регистрация и авторизация пользователей (пароль ≥ 4 символов)
- Добавление доходов и расходов
- Установка лимитов по категориям
- Отчёты по категориям и полный отчёт
- Предупреждения при превышении 80% лимита
- Экспорт транзакций в CSV
- Сохранение данных в файлы (папка `data`)
